# RetroDaD

Update-Quelle für RetroDaD. Die jeweils neueste Fassung liegt als `RetroDaD.zip` im Release **„aktuell“** – sie wird bei jedem neuen Build ersetzt.

RetroDaD holt sie selbst: Einstellungen → Allgemein → RetroDaD-Update → *Nach Updates suchen*.

Im Paket sind nur Programmdateien – keine Spiele, Schlüssel, Firmware oder Spielstände.
